# Strategy

Streamlit 기반 현물 롱 전략 탐색 및 Pine Script v6 생성 앱입니다.

## 실행

```sh
pip install -r requirements.txt
streamlit run app_dashboard.py
```

## 차트별 전략 다양성

- `strategy_search.py`가 기존 5가지 매매 코어와 보조 필터, 청산 방식을 조합합니다. 외부 생성형 AI로 임의의 매매 코드를 만드는 방식은 아닙니다.
- 각 세대에서 전략 유형별 탐색 예산을 균등 배분하고, 신규 무작위 후보를 35% 확률로 투입합니다. 실행마다 독립적인 난수 시드를 만들며 결과에 기록합니다.
- 학습 구간(앞 70%)의 캔들 변동폭과 봉 주기를 이용해 지표 기간, 변동성 필터, 고정 TP/SL, 보유 기간 범위를 조정합니다.
- 최근 100개 생성 이력을 차트 전체에 걸쳐 비교합니다. 비활성 지표나 시뮬레이션에 쓰이지 않는 수치만 다른 후보는 중복으로 봅니다.
- 거래 수, 최대 MDD, 양의 수익률 조건을 만족한 후보 중 최고 적합도에서 15% 또는 15점 이내인 후보를 비교합니다. 새 지표·청산 조합을 우선하고, 최근 덜 선택한 전략 유형에 높은 선택 확률을 줍니다.
- 적합한 새 조합이 없으면 기존 조합을 선택했다는 사실을 화면에 표시합니다. 성능 조건을 만족하는 후보 자체가 없으면 실패로 알리며 결과를 저장하지 않습니다. 매번 다른 전략 유형이나 수익성을 보장하지 않습니다.
- 완료된 생성 ID로 화면 결과를 갱신합니다. 과거 기록을 직접 선택한 경우 다음 생성이 완료되기 전까지 유지합니다.

결과 JSON의 `search_diagnostics`에 시드, 차트 특성, 유형별 평가 횟수, 중복 식별자와 선택 사유가 저장됩니다. `run_ai_evolution_search(..., seed=42)`로 동일 데이터·설정·이력에서 재현할 수 있습니다.

## 검증

```sh
python -m unittest -v test_strategy_search
python verify_strategy_search.py
```

두 번째 명령은 저장된 BTC 1h/15m, ETH 1h, SOL 1h 데이터에서 각각 두 번 탐색합니다. 결과 파일 저장이나 알림 발송 없이 탐색 횟수, 성능 조건, 연속 결과 중복을 검사합니다. Streamlit 브라우저 동작 및 TradingView의 Pine 컴파일 검증은 포함하지 않습니다. 기존 평가 구간(OOS)도 탐색 점수에 사용되므로 독립적인 최종 미사용 검증 구간은 아닙니다.
